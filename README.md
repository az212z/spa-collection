# مجموعة مواقع السبا — ١٠ معاينات خاصة

التشغيل: `npm ci` ثم `npm run dev`، افتح http://127.0.0.1:4180/spa-collection/ .

البناء: `npm run build`. مجلد dist مهيأ لمسار /spa-collection/ على GitHub Pages. النشر تلقائي من main عبر GitHub Actions.

رابط المجموعة: https://az212z.github.io/spa-collection/ .

المسارات: /ri/ /cote/ /wthn/ /flaire/ /tarfah/ /basecoat/ /glowday/ /bannanah/ /relax/ /nanis/ .

المحتوى المركزي src/data.json، الواجهات src/main.jsx، التنسيق src/style.css. المصادر والصور الأصلية محفوظة في research. سجل بيانات البيع prospects.csv وملف التحقق public/research.html.

الحجز طلب موعد عبر واتساب أو فريشا، وليس نظام توافر مرتبطًا بالمركز. لا قاعدة بيانات ولا مدفوعات ولا تخزين لبيانات العملاء. لم يُرسل أي حجز أو رسالة. يلزم ربط تقويم المركز إذا أريد التأكيد الآلي.

قبل التفعيل الرسمي: تحديث الأسعار وساعات العمل مع صاحب المركز، اعتماد المواد والصور، إعادة التحقق من عدم وجود موقع، تخصيص النطاق وقناة الحجز. قائمة نانيس مرتبطة من حسابها لكنها مؤرخة في ٢٠٢٤. لا تستخدم تقرير المصادر كضمان دائم لعدم وجود موقع.
